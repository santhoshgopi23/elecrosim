Your own title block

Press Footer table (Home tab → Annotation, or type FOOTER) to add an editable title-block table to every sheet. Or, for a fully custom one, use the Line, Box, Text and Logo tools in the ribbon at the top (Home tab) to draw yours, then tick Show on every page in the right-hand panel. In a text you can type {page}, {pages}, {title}, {project}, {dwgno}, {rev} or {date} and it is filled in on each sheet.
